# Stay on Log! 🪵

Мобильная мини-игра на чистом HTML / CSS / JavaScript (без зависимостей и сборщика).
Ты — человечек, балансирующий на вращающемся бревне, как лесоруб на сплаве.
Чтобы удержаться, **физически крути телефон**, компенсируя вращение бревна с помощью
акселерометра. Уйдёшь дальше ±90° от верхней точки — падаешь в воду.

## Геймплей

- Бревно постоянно вращается; каждые 5–10 секунд оно случайно меняет направление
  и/или скорость (с предупреждением «⚠ СМЕНА!» за 1.5 секунды до смены).
- Очки = время, проведённое на бревне.
- Сложность растёт по фазам:
  - **0–399 очков** — скорость ограничена 50%.
  - **400–799** — блокируются комбинации «разворот + высокая скорость с обеих сторон».
  - **800+** — без ограничений.
- Ник и рекорд сохраняются в `localStorage`.

> ⚠️ Игра управляется акселерометром, поэтому полноценно играется **только на
> мобильном устройстве**. На десктопе сенсора нет — бревно крутится, но компенсировать
> нечем. (Управление с клавиатуры для десктопа запланировано отдельной задачей.)

## Структура проекта

```
stay-on-log/
├── index.html        # разметка + подключение стилей и модуля
├── css/
│   └── styles.css    # все стили
└── js/
    ├── config.js     # настраиваемые константы (скорости, интервалы, геометрия)
    ├── state.js      # общее изменяемое состояние игры
    ├── dom.js        # кэшированные ссылки на DOM-элементы
    ├── input.js      # обработка акселерометра
    ├── render.js     # анимация падения и брызг
    └── game.js       # точка входа: игровой цикл, поток игры, UI, ник, привязка событий
```

JS подключается как нативный ES-модуль (`<script type="module">`) — сборка не нужна.

## Запуск локально

Из-за ES-модулей файл нельзя открывать по `file://` — нужен локальный сервер:

```sh
# любой статический сервер, например:
python3 -m http.server 8000
# затем открой http://localhost:8000
```

Для проверки управления акселерометром открой страницу с реального телефона
(на iOS потребуется HTTPS и разрешение на доступ к датчикам движения).

## Деплой

Проект — статический сайт, разворачивается на Vercel из ветки `main` без дополнительной
конфигурации.
