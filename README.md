# Stay on Log! 🪵

Мобильная мини-игра на чистом HTML / CSS / JavaScript (без зависимостей и сборщика).
Ты — человечек, балансирующий на вращающемся бревне, как лесоруб на сплаве.
Чтобы удержаться, **физически крути телефон**, компенсируя вращение бревна с помощью
акселерометра. Уйдёшь дальше **±110°** от верхней точки — падаешь в воду.

> ⚠️ Игра управляется акселерометром, поэтому полноценно играется **только на мобильном
> устройстве**. На десктопе показывается заглушка «открой на телефоне». Для отладки на десктопе
> есть скрытый режим **`?dev=1`** (управление с клавиатуры: ←/→ — баланс, Space/↑ — прыжок).

## Геймплей

- Бревно постоянно вращается; каждые 5–10 секунд оно случайно меняет направление и/или скорость
  (с предупреждением «⚠ СМЕНА!» за 1.5 секунды до смены).
- **Очки — событийные**: ~2 очка/сек за выживание **плюс +25 за каждое перепрыгнутое препятствие**.
  Прыжок — по тапу/клику в любом месте экрана.
- **Препятствие**: первые ~25 секунд их нет (грейс-период). Затем по одному — всплывает из воды у
  нижней кромки бревна, доезжает до игрока, и после прохождения ныряет обратно на 1–3 оборота.
  Перепрыгни тапом или потеряешь жизнь.
- **2 жизни**: первый удар мигает ❤️→🤍 и даёт краткую неуязвимость, второй — падение в воду.
- **Сложность растёт по времени**: до 40 c скорость ограничена 50%; 40–80 c блокируются опасные
  «разворот + высокая скорость»; после 80 c — без ограничений.
- **Звук** (синтез Web Audio: прыжок/удар/всплеск/веха) и **вибрация** (Telegram / Web Vibration).
  Кнопка 🔊/🔇 переключает звук; выбор сохраняется.
- **Сочность**: тряска экрана и частицы на событиях.
- Ник, рекорд и настройки чувствительности сохраняются в `localStorage`.
- На первом запуске показывается экран «как играть» с ползунком чувствительности.

## Структура проекта

```
stay-on-log/
├── index.html        # разметка + подключение стилей и модулей
├── css/
│   └── styles.css    # все стили и анимации
├── js/
│   ├── config.js     # настраиваемые константы (скорости, тайминги, инпут, scoring, геометрия)
│   ├── state.js      # общее изменяемое состояние + обёртки localStorage
│   ├── dom.js        # кэшированные ссылки на DOM-элементы
│   ├── input.js      # обработка акселерометра (двухступенчатое сглаживание, чувствительность)
│   ├── obstacles.js  # стейт-машина препятствия (всплытие/ныряние из воды)
│   ├── render.js     # анимация падения и брызг
│   ├── audio.js      # синтез-SFX (Web Audio) + опциональная музыка
│   ├── haptics.js    # вибрация (Telegram / Web Vibration API)
│   ├── fx.js         # juice: тряска экрана, частицы, count-up
│   └── game.js       # точка входа: игровой цикл, поток игры, UI, ник, онбординг, события
├── CLAUDE.md         # гайд для ИИ-агента (архитектура, механики, рабочий процесс)
└── docs/
    └── ROADMAP.md    # беклог, приоритеты, дизайн-заметки
```

JS подключается как нативные ES-модули (`<script type="module">`) — сборка не нужна.

## Запуск локально

Из-за ES-модулей файл нельзя открывать по `file://` — нужен локальный сервер:

```sh
python3 -m http.server 8000
# затем открой http://localhost:8000  (на десктопе — заглушка; для отладки добавь ?dev=1)
```

Для проверки управления акселерометром открой страницу **с реального телефона** (на iOS нужен
HTTPS и разрешение на доступ к датчикам движения).
