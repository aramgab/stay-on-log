# Включение лидерборда (5 минут, один раз)

Код бэкенда уже задеплоен: `api/score.js` и `api/top.js` поднимаются Vercel-ом
автоматически. Пока не заданы переменные окружения, оба отвечают
`503 {"disabled":true}`, и игра просто прячет кнопку 🏆 — ничего не сломано.

Чтобы лидерборд ожил, нужно два шага в дашборде Vercel.

## 1. База: Upstash Redis (бесплатный план)

1. Открой проект **stay-on-log** на [vercel.com](https://vercel.com) → вкладка
   **Storage** → **Create Database / Browse Marketplace** → **Upstash** (Serverless Redis).
2. Создай базу на бесплатном плане (регион любой, ближе к Европе — лучше)
   и **подключи к проекту stay-on-log** (кнопка Connect Project).
3. Интеграция сама пропишет в env проекта `UPSTASH_REDIS_REST_URL` и
   `UPSTASH_REDIS_REST_TOKEN` (или `KV_REST_API_URL`/`KV_REST_API_TOKEN` —
   код понимает оба варианта имён).

## 2. Токен бота

1. Тот же проект → **Settings → Environment Variables**.
2. Добавь переменную:
   - **Name:** `TG_BOT_TOKEN`
   - **Value:** токен @StayOnLog_bot (ты присылал его в чате; всегда доступен
     в BotFather → @StayOnLog_bot → API Token)
   - Environments: Production (можно все).
3. **Redeploy**: вкладка Deployments → у последнего деплоя меню ⋯ → Redeploy
   (env подхватываются только новым деплоем).

## 3. Проверка

- `https://stay-on-log.vercel.app/api/top` в браузере → должно вернуть
  `{"top":[],"me":null}` вместо `{"disabled":true}`.
- Сыграй забег в Telegram → на старте появится кнопка 🏆, а твой счёт
  попадёт в топ.

## Безопасность

- Токен живёт ТОЛЬКО в env Vercel — в публичный репозиторий он не попадает.
- Поскольку токен успел засветиться в чате с агентом, хорошая практика —
  после настройки перевыпустить его в BotFather (`/revoke`) и обновить
  значение `TG_BOT_TOKEN` в Vercel. Mini App при этом продолжит работать,
  главное — чтобы новый токен оказался в env до следующего redeploy.
- Сервер валидирует подпись `initData` (HMAC с токеном) и пишет очки через
  `ZADD GT` — чужой счёт подделать нельзя, свой можно только повысить,
  санити-кап 50000.
