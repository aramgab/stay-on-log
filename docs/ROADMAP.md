# Roadmap — Stay on Log

Беклог, приоритеты и дизайн-заметки. Контекст для продолжения работы в новой сессии.
Это карта намерений; **что реально реализовано — смотри в коде** (`js/`).

Сквозной принцип: **сначала честная и приятная одиночная сессия → социалка → экономика →
дистрибуция.** Скины без ретеншна не окупаются.

- **Этап 1.2 «контроль-фил и отдача» (июль 2026, ждёт плейтеста):**
  - **Steering assist («гидроусилитель»)**: игра сама компенсирует долю вращения бревна —
    `ASSIST_PHASE_FACTOR=[0.30, 0.18, 0.10]` по фазам (новичкам легче, поздняя игра скилловая);
    глобальный множитель — слайдер «assist» в `?dev=1` (`stayOnLog_assistMult`).
  - **Danger-виньетка**: красное свечение края экрана со стороны сноса, от `DANGER_WARN_FROM=55°`
    до полной яркости у порога падения — телеграф «почему я упал».
  - **Процедурная музыка** (Web Audio, без ассетов): бас+арпеджио+пад, lookahead-планировщик;
    настроение (BPM/лад/плотность) следует биому: день 96bpm мажор → шторм 116bpm минор.
    mp3-путь удалён; unmute теперь возвращает музыку сразу.
  - **Хаптики на позитив**: клир/комбо, тики отсчёта 3-2-1, смена биома, «новый рекорд»
    (раз за забег, не на первом забеге). Ограничение платформы: вне Telegram на iOS вибрации
    невозможны вовсе (нет API в Safari) — внутри TG работает `HapticFeedback`.

- **Этап 2 «TG-нативность без бэкенда» (июль 2026, ждёт плейтеста):**
  - **Личность из TG**: ник по умолчанию из `initDataUnsafe.user` (first_name/username) — внутри
    Telegram оверлей «как тебя зовут?» больше не показывается. Приоритет: введённый вручную >
    CloudStorage > TG-профиль (см. `nameSource` в game.js). Весь доступ к SDK — через новый `js/tg.js`.
  - **Рекорд и ник в `CloudStorage`** (клиенты ≥6.9, гард версии): async-merge на загрузке —
    больший рекорд побеждает, локальное всегда работает мгновенно; пуш в облако на новом рекорде
    и при смене ника.
  - **Кнопка «Похвастаться»** (`#share-btn`, видна при рекорде > 0): Telegram `t.me/share/url` →
    Web Share API → буфер обмена («Скопировано!»). Пока шарится прямой URL (`SHARE_URL` в
    config.js) — deep-link `t.me/<bot>/<app>?startapp=…` требует бота, которого нет до этапа 3.
  - **Клавиатурный режим на десктопе**: в заглушке кнопка «🎹 Играть с клавиатурой» (←/→, пробел) —
    расшаренные ссылки в Desktop Telegram/браузере больше не тупик; `?dev=1` теперь отвечает
    только за панель тюнинга.
  - **Нормализация delta-time** (закрыт блокер качества из этапа 6): скорости = «градусы за кадр
    60 Гц» на любом дисплее (dtF в gameLoop, клэмп 50мс); `state.elapsed` копится по живым
    кадрам — свёрнутое приложение не фармит очки выживания и не прыгает по фазам/биомам.
    На 60 Гц поведение идентично прежнему; если темп на устройстве заметно упал — экран был
    90/120 Гц: перетюнить `MIN_SPEED`/`MAX_SPEED`, **не** revert.

  - **Смягчение фазы 3** («бешеное бревно» после ~200 очков): запрет высокоскоростных

  - **Revive** «⚡ Продолжить за 40 🪙» на экране смерти (раз за забег): тот же
    score/elapsed/combo/биом, hp=1, щит 1.8с, быстрый отсчёт, свежие препятствия.
  - **Лидерборд**: `api/score.js`+`api/top.js` (Vercel serverless, zero-deps, HMAC-валидация

## Этап 7 — Контент-лонгтейл (P3)
- Биомы, влияющие на физику (шторм — качка `game-container`), пауэр-апы (щит/слоу-мо/магнит),
  ежедневные челленджи.
- **Новые биомы-темы (идея 5 июля 2026)** — расширяют текущую систему день/закат/ночь/шторм
  (`applyBiome` в `game.js`, палитра на CSS-переменных): каждый — новая палитра + свой тип
  препятствия, вписанный в существующий `OBSTACLE_TYPES` (стейт-машина `submerged ⇄ active`
  не меняется, меняется только арт/хитбокс):
  - **Снежный**: лёд вместо коры/воды, препятствия — ледяные шипы (аналог `knot`/`branch`
    визуально «остро», возможно синергия со скольжением — под вопросом, не переусложнять физику).
  - **Лавовый**: лава вместо воды (падение = сгорание, не всплеск — свой `render.js`-эффект),
    препятствия — горячие камни/угли.
  - **Цифровой**: вместо бревна — биткоин (крутящаяся монета вместо коры-цилиндра, самый
    смелый арт-своп из всех), внизу вместо воды — опенспейс со старыми большими компьютерами,
    по фону ходят люди в очках и белых сорочках (декоративный параллакс-слой), препятствия —
    компьютерные мышки. Самый затратный по арту биом — кандидат делать последним/как ивент.
  Порядок появления и правила разблокировки — см. «Открытие биомов со временем» в Этапе 4.
