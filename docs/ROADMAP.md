# Roadmap — Stay on Log

Беклог, приоритеты и дизайн-заметки. Контекст для продолжения работы в новой сессии.
Это карта намерений; **что реально реализовано — смотри в коде** (`js/`).

## Уже сделано
- Сплит на ES-модули, деплой на Vercel из `main`.
- Управление наклоном; порог падения **±110°**.
- Заглушка на десктопе + скрытый dev-режим `?dev=1` (клавиатура + живые слайдеры тюнинга инпута).
- Одно препятствие со всплытием/нырянием из воды; грейс-период 25 c; прыжок по тапу; 2 жизни.
- Синтез-SFX (Web Audio) + вибрация (Telegram/Web Vibration); mute с сохранением.
- **Фикс фила инпута**: двухступенчатое сглаживание (EMA скорости + low-pass позиции), без дрейфа.
- **Онбординг**: экран «как играть» на первом запуске + ползунок чувствительности.
- **Событийный scoring**: очки = выживание + бонус за перепрыгивание (не чистый таймер).
- **Juice**: тряска экрана, частицы (`fx.js`).

## Ближайшая очередь (по запросу пользователя, делаем по одному заходу)
1. **Прыжок** — без фриза фигурки в воздухе/на земле; без задержки, прыжок по каждому тапу.
   *(итерации откатывались; текущее состояние сверять с `git log` и `game.js`/CSS `playerJump`).*
2. **Препятствия → сучки.** Сделать заметнее по цвету (мох — сейчас сливаются с бревном),
   форма не «шипы», а «сучки», **минимум 3 разновидности**.
3. **UI без наслоения.** Информация в верхней зоне (очки/рекорд/жизни/статус/стрелка) налезает
   друг на друга и на бревно — развести/уплотнить лейаут.

## Беклог (P0…P3)
Сквозной принцип: **сначала честная и приятная одиночная сессия, потом социалка, потом экономика.**
Скины без ретеншна не окупаются.

### P1 — социальная петля (главный драйвер ретеншна/виральности в Telegram)
- **TG-нативная личность + лидерборд + шаринг.** `initDataUnsafe.user` вместо самописных ников;
  рекорд в `CloudStorage`; кнопка «поделиться счётом» / «обгони меня»; топ друзей.
  Это №1 органический канал роста в TG. Главный риск скоупа — бэкенд лидерборда.
- **Глубина препятствий и прыжка.** 2–3 типа (низкая ветка — присед/наклон; двойное — ритм;
  разрыв — тайминг). Лечит однообразие; даёт чем хвастаться.

### P2 — экономика (когда уже есть что удерживать)
- **Монетки + комбо** на событийном scoring: монета за пройденное препятствие и за серию; комбо
  ×множитель к монетам, сброс при ударе. Автозачёт при прохождении (тап занят прыжком — не «касанием»).
  Ориентир цен: скин 150–400 монет, ~8–15 монет за хороший забег.
- **Скины бревна/персонажа + магазин** (данными, выбор в localStorage). Бесполезны без P1.

### P3 — разнообразие / лонгтейл
- **Биомы/погода**: палитры день→закат→ночь→шторм по вехам; шторм влияет на физику.
- **Пауэр-апы** (щит / слоу-мо / магнит) — отложено осознанно, после экономики.

## Дизайн-заметки и известные риски
Кандидаты на проверку плейтестом на реальном телефоне:
- **Контроль-фил** — корень удержания первой сессии. Любой регресс инпута бьёт по D1 сильнее любой
  косметики. Держать тюнинг в `config.js` + слайдерах `?dev=1`.
- **Честность телеграфа препятствия.** Реверс направления (каждые 5–10 c) во время подлёта
  препятствия может «вернуть» его вниз и привести с другой стороны → риск нечестной смерти или
  путаницы. Проверить: нужен ли явный индикатор «откуда придёт» и/или блок реверса, пока препятствие активно.
- **Грейс 25 c** до первого препятствия — длинновато для hyper-casual; следить за скукой в начале.
- **±110°** — широкая зона; пощупать, не теряется ли ощущение «балансирую на грани».
- **Десктоп-заблокирован** режет шаринг-трафик в Desktop Telegram — рассмотреть клавиатурный фолбэк
  для расшаренных ссылок (сейчас только под `?dev=1`).
- **TG-нативность** пока минимальна (только `ready/expand`) — `initData`, `CloudStorage`, `MainButton`,
  шаринг не используются; это самый дешёвый виральный ROI.
- **iOS-пермишен на датчики** (`DeviceMotionEvent.requestPermission`) — потенциальная точка оттока в воронке.
