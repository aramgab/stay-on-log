# Roadmap — Stay on Log

Беклог, приоритеты и дизайн-заметки. Контекст для продолжения работы в новой сессии.
Это карта намерений; **что реально реализовано — смотри в коде** (`js/`).

Сквозной принцип: **сначала честная и приятная одиночная сессия → социалка → экономика →
дистрибуция.** Скины без ретеншна не окупаются.

## Этап 3 — Лидерборд + бэкенд (P1)
**Рекомендация: Vercel serverless в этом же репо** — папка `api/` (`score.js`, `top.js`)
подхватывается Vercel без билд-шага, статика не затрагивается; БД — Upstash KV (sorted set
идеален для лидерборда) или Neon Postgres, бесплатных лимитов хватит с запасом.
Обязательно: серверная валидация TG `initData` (HMAC с bot token в env Vercel) — иначе накрутят.

Домашний Windows-ноутбук как сервер — честная оценка: нужен Cloudflare Tunnel (HTTPS/домен),
риски аптайма (Windows Update, свет, сон), безопасность домашней сети, латентность для
глобальной аудитории. Годится как песочница для экспериментов, но не как прод; Vercel-вариант
при этом бесплатен и деплоится тем же `git push`.

## Этап 4 — Экономика (P2)
- Монеты за пройденные сучки и серии — комбо уже есть как фундамент (монеты = f(eventScore)).
- Скины бревна/персонажа = наборы CSS-переменных (палитро-система делает их почти бесплатными);
  выбор в localStorage/CloudStorage; магазин — данными в JS-объекте.
  Ориентир цен: скин 150–400 монет, ~8–15 монет за хороший забег.

- Предусловие Этапа 6.

## Этап 6 — Магазины приложений (P2-P3)
- **Google Play**: TWA через Bubblewrap (нужен готовый PWA + `assetlinks.json`).
- **iOS**: Capacitor-обёртка (аккуратно с motion-permission в WKWebView).
- **Блокер качества перед сторами/лидербордом: нормализация по delta-time.**
  `logSpeed` сейчас в градусах/кадр rAF (`game.js`, шаг 1) — на 90/120 Гц экранах игра
  в 1.5–2× быстрее, чем на 60 Гц. Фикс меняет глобальный фил (категория риска как у инпута) —
  отдельный тщательно тестируемый коммит, не молча.
